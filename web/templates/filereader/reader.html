File reader

Open a PageMaker, InDesign (IDML) or PDF file and see every page with its text where it sits in the original. Legacy Malayalam fonts such as ML-TT are converted to Unicode. Nothing you upload here is stored.

{% csrf_token %}

Have an InDesign .indd file? In InDesign, choose File > Export and pick "InDesign Markup (IDML)", then upload that. "Convert to InDesign" turns a PageMaker file into an .idml that InDesign CS4 or later opens; save it there as .indd. InDesign CS3 can't open IDML, so for CS3 download the script instead and run it from InDesign's Scripts panel (Window > Automation > Scripts); it saves the .indd on your desktop. To convert many PageMaker files at once, select them all (up to 30 MB together): you get one script that saves every one of them as .indd.
